## For Collaborators

When others clone this repository, they'll need to:

1. **Download raw DDXPlus data** (from the original source)
2. **Run preprocessing**: `uv run preprocess_ddxplus.py`
3. **Validate**: `uv run validate_preprocessing.py`

This ensures everyone has the exact same preprocessed data (random seed 42).
